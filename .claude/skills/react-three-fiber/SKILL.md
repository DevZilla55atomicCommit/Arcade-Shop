# React Three Fiber Skill

Use when building 3D scenes with React Three Fiber.

## Core Concepts

- Canvas component for WebGL context
- useFrame for render loop
- useThree for scene access
- Drei helpers (Html, Text, Environment, etc.)
- Shader materials for custom effects
- Instanced meshes for performance

## Arcade Scene Components

- ArcadeGrid (animated grid floor)
- NeonTubes (floating neon tubes)
- PixelParticles (particle system)
- ArcadeCabinet (hero 3D model)
- CRTShaderMaterial (CRT effect)

## Performance

- Frustum culling
- Level of detail
- Texture compression
- Reduce draw calls
- Dispose geometries/materials
- Use useMemo for static objects

## Arcade Theme

- Neon color palette
- Glowing materials
- Additive blending
- Scanline shaders
- Vignette effects
