# Modern Web Design Skill

Use when implementing modern design trends and micro-interactions.

## 2024-25 Trends

- **Bold Minimalism**: High contrast, generous whitespace, dramatic typography
- **Scrollytelling**: Narrative-driven scroll experiences
- **Glassmorphism**: Frosted glass with backdrop blur
- **Bento Grids**: Card-based dashboard layouts
- **Cursor UX**: Custom cursors, magnetic elements
- **Kinetic Typography**: Text that moves with purpose
- **Dark Mode First**: Designed for dark, light as variant

## Arcade Theme Application

- Neon glow as primary accent
- Pixel borders on cards/buttons
- CRT scanline overlays
- Marquee text elements
- Magnetic hover interactions
- Particle backgrounds
- Retro loading states

## Micro-Interactions

- Button press: pixel bounce
- Hover: neon glow + scale
- Focus: visible ring + glow
- Loading: arcade spinner
- Transitions: slide + fade
- Scroll: parallax + reveal
