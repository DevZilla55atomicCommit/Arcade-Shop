# Locomotive Scroll Skill

Use when implementing smooth scroll with Locomotive Scroll.

## Setup

- Initialize on scroll container
- Connect to GSAP ScrollTrigger
- Update on route changes
- Destroy on unmount

## Configuration

- lerp: 0.08 (smoothness)
- smoothMobile: false
- tablet/smartphone breakpoints
- scrollFromAnywhere: true

## Integration

- data-scroll-container on root
- data-scroll-section for sections
- data-scroll for animated elements
- data-scroll-speed for parallax
- data-scroll-direction for direction awareness

## Arcade Theme

- Neon scrollbar
- Smooth momentum feel
- Scroll progress indicator
- Back to top button
