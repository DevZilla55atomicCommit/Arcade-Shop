# Motion Framer Skill

Use when implementing React animations with Framer Motion.

## Key Patterns

- Variants for reusable animation states
- AnimatePresence for exit animations
- Layout animations with layout prop
- Gesture animations (whileHover, whileTap, whileDrag)
- Scroll animations with useScroll/useTransform
- Stagger children with staggerChildren

## Arcade Theme Variants

- neonPulse, neonFlicker
- pixelBounce
- fadeInUp, fadeInDown, slideInLeft, slideInRight
- scaleIn
- staggerContainer, staggerItem
- pageTransition
- marquee

## Performance

- Use layoutId for shared element transitions
- Memoize heavy components
- Use transform over layout properties
- Reduced motion support required
